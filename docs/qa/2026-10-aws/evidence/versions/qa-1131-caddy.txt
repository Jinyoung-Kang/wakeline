## 닿는 경로 — 실제 Caddyfile 처럼 auto_https off · 평문 리스너(protocols 미지정 = 기본값)에서 HTTP/2(h2c) 를 받는가
probe Caddyfile:
    {
    	auto_https off
    	admin off
    }
    :8103 {
    	header -Server
    	respond "ok" 200
    }
$ curl -sS -o /dev/null -w "%{http_version} %{http_code}" http://127.0.0.1:8103/                         (같은 망 이름공간, curl 은 wakeline-api:qa 의 것)
1.1 200
$ curl … --http2-prior-knowledge http://127.0.0.1:8103/
2 200
→ 평문 리스너가 h2c(사전 지식)를 받는다: HTTP/2 서버 CVE(78669 · 78663 · 97032)는 리스너에 TCP 로 닿는 누구에게나 열린다. 운영의 보안 그룹(CloudFront 원본 대역만 — Caddyfile 머리말)은 이 QA 에서 확인하지 않았다.
