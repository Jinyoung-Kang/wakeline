### 고치며 정한 것(설계 판단 — 병합 전에 되돌릴 수 있다)
- **QA-600**: DB 가 없으면 공항 줄을 빼고(`airports: []`) `meta.db_unavailable: true` — `found: false` 로 지어 보이지 않는다(제품 규칙 '모르면 —'). 다른 공개 조회의 관례 그대로.
- **QA-709**: '발효 중' = 발효 시각이 지난 정규 특보. 예비 · 발효 예정은 "발효 예정 N · 예비 M" 으로 따로. 정규 특보에 발효 시각이 없으면 발효 중(목록이 기상청 '특보현황').
  E2E(`e2e/warnings.spec.ts`)의 기대 문구가 바뀌었다 — fixture 의 3건은 모두 예비라 "발효 중 0건 · 예비 3".
- **QA-711**: ±100,000 ft(FL999) 밖의 고도 값은 숫자가 아닌 값과 같이 `UNKNOWN`(모듈 규칙) — 공식 파일 전체를 거절하지 않는다. 재현 시험의 그 경우 기대를 이 규칙으로 바꿨다.
- **QA-705**: WS 기준은 첫 전체 목록(`alertsVersion`) 뒤에 잡는다 — 기존 `tests/watch-runner.test.ts` 가 `alertsVersion` 없는 목록을 쓰던 것을 실제와 같게 고쳤다.

## 개선 제안(구조 · 일관성 — 결함 아님, 고치지 않음)
1. `String.strip()` 은 탭 · 줄바꿈 · `\u001F` 도 공백으로 지운다 — `Params.hex/icao/int` · `RetainTargets` 가 그 값을 받아들인다(§G43 "공백 글자만"의 뜻과 다를 수 있음). QA-500 처럼 ASCII 공백만 지우는 공통 함수로 모으기.
2. `WatchButton` 의 `aria-pressed` 와 바뀌는 이름이 함께 쓰인다(토글 단추는 이름을 고정하는 편이 낫다 — WAI-ARIA APG).
3. `/alerts/{id}` 가 열린 알림에도 DB 사본(구역)을 읽는다 — 메모리 사본으로 충분한 경우가 있다.
4. 지정 보존 조회의 72 h 경계를 걸친 창(원해상도 + 보존 점을 섞지 않고 한쪽만 — ADR-038 §5)은 문서화된 한계 — 섞는 조회를 검토.
5. 실행기의 `seenAlerts` 가 알림 id 를 계속 쌓는다(오래 연 탭) — 닫힌 알림 id 를 주기적으로 버리기.
6. 관심 탭 상태 줄(aria-live)이 30 s 마다 같은 글을 다시 알린다.
7. 공항 비행 등급이 '모름'을 거쳐 바뀌면 사건이 나지 않는다(모름 → X) — 의도한 보수적 규칙이나 설명서에 적기.
8. 특보 응답의 BOM · 같은 줄 중복 · `kma_warning_state` 해시 · 9열 대체 형식의 처리를 시험으로 고정하기.
9. 버린 줄(dropped)의 특보는 목록에서 빠진 것과 같아 이력에서 그 목록의 수신 시각으로 끝난다(ADR-036 결정 4 그대로 — `WarningRepository.persist`). 같은 특보가 다음
   주기에 정상이면 다시 열려 이력이 끊긴다. `dropped > 0` 인 목록에서는 끝내지 않는(또는 버린 줄의 구역만 남기는) 편을 검토 — 제품 판단.
10. 관심 탭이 `/watch` 의 `meta.db_unavailable` 을 읽지 않아 DB 장애 동안 공항 줄이 까닭 없이 "—" 다(§G53 과는 맞다) — 항공기 · 선박 카드처럼 'DB 일시 사용 불가'를 적기.
11. 구조 가드: `ArchitectureTest`(api) · `test_layering.py`(수집기) 모두 통과 — 새 위반 · 순환 0.

## 시험이 없는 중요한 경로
- 특보 목록에서 줄을 버린(dropped) 주기의 이력 처리(지금은 끝냄 — 개선 제안 9)를 api 통합 시험으로 고정.
- `/watch` 숨은 탭 조회를 실제 브라우저(백그라운드 탭 · 알림 허락 바뀜)에서 — 지금은 mini-dom 단위 시험.
- 보존 복사(`copyRetained`)와 72 h 파티션 삭제의 순서(같은 시간에 둘 다 돌 때).
- 운영 도구의 명령 끝(`tools/airspace_import.main` — 표준 입력 · 종료 코드 · DB 실패 글)을 실제 PostGIS 로 — DB 쓰기 자체는 `test_db_pg_integration.py` 가 본다.
