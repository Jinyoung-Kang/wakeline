# ADR-016 항공기 출발지·도착지: 선택할 때만 adsbdb 에 묻고, 저장하지 않는다

**상태** 채택 · 2026-09-28 · 계약 v4 §A

## 맥락
ADS-B 신호에는 출발지·도착지가 없다. 알 수 있는 것은 콜사인(편명)과 ICAO 24-bit 주소뿐이다. 출발·도착을 보이려면 "콜사인 → 등록 노선" 자료가 필요하다.

## 확인한 사실(2026-09-28)
- adsb.lol `POST /api/0/routeset`(이미 쓰는 공급자, OpenAPI 의 요청 모양 그대로): 두 번 모두 HTTP 201 + 빈 본문(content-length 0). 지금은 쓸 수 없다.
- adsbdb.com `GET /v0/callsign/{CALLSIGN}`: HTTP 200 + 항공사·출발·도착(선택적으로 경유) 공항의 ICAO·IATA·이름·도시·국가·좌표. 예: APJ736 = 김포(RKSS) → 간사이(RJBB).
- adsbdb README: 노선 자료는 David Taylor(Edinburgh)·Jim Mason(Glasgow)의 작업이며 "David J Taylor 의 명시적 허락 없이 복사·게시·다른 데이터베이스에 넣지 말 것". 호출 한도는 적혀 있지 않다.
- OpenSky `/flights/aircraft` 는 밤에 일괄 처리된 지난 비행만 준다 — 지금 비행의 출발·도착에는 쓸 수 없다.

## 결정
1. adsbdb 를 **선택한 항공기(집중 추적 임대)에 대해서만** collector 가 묻는다. 한 콜사인은 30분에 한 번까지(캐시), 호스트 0.5 req/s · 하루 2,000회 상한.
2. **저장하지 않는다.** PostgreSQL·파일·원천 보관에 쓰지 않고, Redis 에 30분 TTL 로만 둔다(같은 항공기를 여러 사람이 볼 때 다시 묻지 않으려는 캐시). 로그에는 콜사인·상태만.
3. 화면은 이것이 **콜사인에 등록된 정기 노선**이며 실제 운항과 다를 수 있다고 적는다. 대신 현재 위치와 노선 대권 경로 사이 거리(계산값)를 함께 보여 판단 근거를 준다.
   우리가 "맞다/틀리다" 를 추정해 붙이지 않는다.
4. 출처를 카드와 `/about` 에 적는다.

## 결과
- 선택 후 첫 노선은 집중 추적 한 주기(약 5 s) 뒤에 뜬다. 공급자가 모르거나 실패하면 그 사실을 그대로 보인다.
- 약관: 우리 서비스는 로컬·비상업이며 자료를 모으지 않는다. 공개 배포하려면 자료 저작자의 허락을 받아야 할 수 있다 — 배포 전 결정 사항으로 남긴다.
