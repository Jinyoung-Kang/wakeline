# ADR-037 관심 대상 · 브라우저 알림 — 목록은 브라우저에만, 상태는 한 요청으로, 사건은 브라우저가 찾고, 숨은 탭 예외는 하나

**상태** 채택 · 2026-10-09 · 사용자 승인("권장안대로" — [계획](../plans/features-2026-10/PLAN.md) §9 결정 D5) · [SPEC](../plans/features-2026-10/SPEC.md) F4 ·
계약 [v5 §G50](../audit/change-contract-v5.md) · [ADR-029](ADR-029-web-data-access.md) §5(숨은 탭은 멈춤)의 예외 · [VERIFICATION](../VERIFICATION.md) #121

## 맥락
- 판정 엔진(SIGMET · 공역)은 모든 항공기를 보지만, 사용자는 몇 대 · 몇 척 · 몇 공항만 지켜보고 싶다. 계정이 없다(로컬 1인 운영).
- ADR-029 §5-2: 숨은 탭에서는 주기 요청 · WS 를 멈춘다. 숨은 탭에서 아무것도 받지 않으면 브라우저 알림이 쓸모없다.
- 첫 화면 JS 예산(ADR-026 · 550,000 B, 단계 2–5 합쳐 +300 B 목표)이 빠듯하다.

## 결정
1. **목록은 이 브라우저에만**(`localStorage` `wakeline.watch` · 50개 · 형식 검사 — 깨진 값은 버리고 알린다, 못 쓰면 '이번 접속 동안만'). 서버는 저장하지 않는다.
2. **상태는 한 요청**: `GET /api/v1/watch?aircraft=&ships=&airports=`(§G50 · 합쳐 50개). 항공기 · 선박은 메모리, 공항은 최신 METAR(DB — 메모리에 없다, 공항마다
   색인 한 번 — 계획의 '메모리만'에서 바꾼 것). 최근 15분 안에 닫힌 알림은 `watch.RecentClosedAlerts` 가 엔진 사건에서 모은다(5,000건 상한). `private, max-age=5`.
3. **사건은 브라우저가 찾는다**(`lib/watch.ts` — React 없음): 이전 답 ↔ 새 답(첫 답은 기준 — 열자마자 쏟아지지 않게) · WS 알림(새 id 만, 시작할 때 있던 것은 기준)을
   같은 사건 열쇠로. 같은 열쇠는 한 번, 같은 대상 · 같은 종류는 10분 안에 되풀이하지 않는다. 사건: 진입 · 예측 진입 · 알림 닫힘(까닭) · 신호 끊김 / 선박 30분 끊김
   (열린 AIS 공백의 까닭) · 다시 받음 / 공항 비행 등급 변화(둘 다 아는 값일 때만).
4. **알림 방법**: 화면 안 배너(늘) + 브라우저 알림(사용자가 '알림 켜기' 단추로 허락했을 때만 — 서비스 워커 · 푸시 구독 없음, 탭이 열려 있을 때만). 누르면 그 대상의 카드.
5. **숨은 탭 예외(이것 하나)**: 관심 대상이 있고 알림을 허락했을 때만, 숨은 동안에도 `/api/v1/watch` 를 30 s 에 한 번. WS · 지도 · 다른 주기 요청은 그대로 멈춘다.
   조건은 `pollWhileHidden` 하나, 쓰는 곳도 실행기 하나(시험이 고정). 끄는 법: 관심 대상을 비우거나 브라우저에서 알림 허락을 거둔다.
6. **첫 화면 밖**: 실행기 · 관심 탭 · 단추는 조각. 실행기는 첫 화면 뒤 미리 받기가 받은 뒤에만 그린다(`WatchRunnerPart.useLoaded()` — 받기를 앞당기지 않는다).

## 버린 대안
- **서버에 목록 저장 · 서버가 사건 판정**: 계정 · 저장 · 사생활 문제가 생긴다. 사건 판정은 이전 답과 비교하면 충분하다.
- **실행기를 `createRoot` 로 문서 끝에 따로 그리기**: `react-dom/client` 를 조각이 부르자 Turbopack 이 첫 화면 런타임 청크를 둘로 나눠 첫 화면 JS 가 +416 B
  (압축 손실). 조각의 `useLoaded` 로 바꿔 +184 B(PERF §18).
- **관심 대상이면 집중 추적 임대를 자동으로**: 공급자 예산을 개인 목록이 쓰게 된다. 목록에 '받는 범위 밖은 판정 안 됨'을 적는다.
- **웹 푸시(브라우저를 닫아도)**: 서비스 워커 · 푸시 서비스(외부 발신)가 필요하다 — 이번 범위 밖.
